=== demarrage
# Открытие и сохранение

## Начало {#nouveau}

DocCells открывается с пустой книгой из одного листа. Чтобы снова начать с пустой книги, обновите страницу или откройте DocCells в другой вкладке браузера.

## Открыть книгу {#ouvrir}

| Способ | Результат |
| --- | --- |
| {open}, **%file% › %open%**, [[Ctrl+O]] | выбрать файл `.xlsx` на компьютере |
| Перетащить файл на страницу | завеса показывает, куда его отпустить; книга заменяет открытую |
| **%file% › %openRecent%** | десять последних открытых или сохранённых файлов (Chrome и Edge) |
| Ссылка `?url=…` | книга в интернете или Google Таблица ([публикация](partager.html#url)) |

Читается только формат Excel `.xlsx`. Старые файлы `.xls`, а также `.ods` и `.csv` нужно сначала преобразовать. Что сохраняется из файла Excel, описано в разделе [Совместимость с Excel](excel.html).

warn: Открытие книги заменяет показанную: сначала сохраните изменения.

### Недавние файлы {#recents}

Браузер может снова запросить разрешение на чтение файла. Перемещённый, переименованный или удалённый файл убирается из списка. **%clearRecentFiles%** очищает его. Список хранится в этом браузере, на этом компьютере.

## Сохранение {#enregistrer}

### Chrome и Edge

| Команда | Результат |
| --- | --- |
| {save}, **%file% › %save%**, [[Ctrl+S]] | в первый раз спрашивает, куда поместить файл; затем заменяет его без вопросов |
| **%file% › %saveAs%** | выбрать другой файл |

Файл, открытый кнопкой {open}, из списка недавних или перетаскиванием, сохраняется на своём месте; браузер один раз запрашивает разрешение на изменение.

Имя книги стоит в конце строки меню. Красная точка означает несохранённые изменения; заголовок вкладки браузера тогда начинается с ●.

### Firefox, Safari

Эти браузеры не позволяют записывать в файл. **%file% › %export%** или [[Ctrl+S]] скачивает книгу под именем открытой.

## Восстановление несохранённой книги {#recuperer}

Пока есть несохранённые изменения, DocCells хранит в браузере копию, обновляемую менее чем через секунду после каждого изменения. Если страница закрыта без сохранения, при следующем открытии DocCells предлагает, с датой копии, восстановить её (**%restore%**) или нет (**%ignore%**).

- Сохранение, экспорт или открытие другой книги стирает эту копию.
- Отказ от копии удаляет её окончательно.
- Копия создаётся, только когда DocCells занимает всю страницу, а не встроен в другую.

## Язык {#langue}

DocCells берёт язык браузера из двенадцати языков интерфейса: английский, греческий, испанский, итальянский, китайский (упрощённый и традиционный), немецкий, нидерландский, португальский, русский, французский, хинди. Для остальных используется английский. `?lang=ru` в адресе задаёт язык.

Язык меняет меню, имена функций, десятичный разделитель, символ валюты и порядок отображаемых дат. Сохранённый файл от него не зависит: книга, написанная по-французски, открывается по-немецки с немецкими формулами.

## Лист {#feuille}

- Щелчок правой кнопкой открывает меню в зависимости от места: ячейка, заголовок столбца или строки, вкладка листа.

## Отмена {#annuler}

Диаграммы в неё не входят: их [изменяют или удаляют](graphiques.html#modifier) их кнопками.

# Ввод данных

## Запись в ячейку {#ecrire}

| Действие | Результат |
| --- | --- |
| набрать в выделенной ячейке | заменяет её содержимое |
| двойной щелчок, [[F2]] или [[Enter]] | изменяет её содержимое |
| [[Enter]] | подтверждает и переходит на ячейку вниз |
| щелчок по другой ячейке | подтверждает |
| [[Esc]] | отказ от ввода |
| [[Alt+Enter]] | новая строка внутри ячейки |
| [[Delete]] или [[⌫]] | очищает выделенные ячейки вместе с флажками и списками; оформление остаётся |
| правая кнопка › **%clearContent%** | то же |

Во время ввода стрелки перемещают курсор в тексте. В остальное время стрелки, [[Tab]] и [[Shift+Tab]] меняют ячейку.

## Что распознаёт DocCells {#types}

| Набирают | Получают |
| --- | --- |
| `12`, `-3`, `1e5` | число, выровненное вправо |
| `n:2.5` | десятичное число; разделитель — запятая |
| `n:1,234.5` | число 1234,5; чтобы показать пробел между тысячами, выберите [формат](nombres.html) |
| `25%`, `n:2.5%` | процент |
| `2026-11-25`, `2026/11/25` | дата |
| `2026-11-25 14:30` | дата и время |
| `TRUE`, `FALSE` | логическое значение |
| `n:[2, 1]` | [список](listes.html) |
| `=A1+B1` | [формула](formules.html) |
| всё остальное | текст, выровненный влево |

### Даты {#dates}

Дата набирается начиная с года: `2026-11-25`. `25.11.2026` остаётся текстом, с которым нельзя вычислять. Чтобы изменить её вид, выберите **%format% › %number% › %fDate%** (`%xDate%`) или [пользовательский формат](nombres.html#personnalise).

Двойной щелчок по ячейке с датой открывает [календарь](controles.html#calendrier). `=TODAY()` даёт сегодняшнюю дату.

### Тексты из цифр {#textes}

Номер, начинающийся с нуля, теряет его: `007` становится 7. Чтобы сохранить ноль, заранее задайте ячейкам формат **%fText%** (**%format% › %number% › %fText%**) или начните с апострофа: `'007`.

## Частые ошибки ввода {#erreurs}

| Видно | Причина |
| --- | --- |
| число выровнено влево | это текст: точка вместо запятой, единица (`12 ₽`), лишний пробел |
| `46351` вместо даты | дата в формате **%fGeneral%**: задайте ей формат **%fDate%** |
| текст обрезан соседней ячейкой | расширьте [столбец](lignes-colonnes.html#taille) или выберите **%wrap%** |

Для единицы введите только число и задайте ему [формат](nombres.html): денежный или пользовательский, например `c:0.00 "m"`.

## Копировать, вырезать, вставить {#copier}

[[Ctrl+C]], [[Ctrl+X]], [[Ctrl+V]] или **%copy%** и **%paste%** в меню правой кнопки.
- **%paste%** в меню правой кнопки вставляет значения без формул; [[Ctrl+V]] вставляет формулы.
- Вставленная формула следует новому месту: `=B2`, скопированная на строку ниже, становится `=B3`. Знак `$` закрепляет строку или столбец ([ссылки](formules.html#references)).
- Вырезанная формула сохраняет свои ссылки.
- Таблица, скопированная из Excel, Numbers, с веб-страницы или из текста с табуляцией, вставляется по ячейкам; десятичные числа и списки распознаются как при наборе.
- Несколько диапазонов сразу вырезать или вставить нельзя.

## Перемещение {#deplacer}

Потяните границу выделения: ячейки перемещаются вместе с оформлением.

## Заполнение {#recopier}

Синий маркер в правом нижнем углу выделения тянут вниз, вверх, влево или вправо.

| Исходные ячейки | Маркер даёт |
| --- | --- |
| формула | формулу со сдвинутыми ссылками |
| два числа, 1 и 2 | ряд: 3, 4, 5… |
| одно число, текст или дата | то же значение |
| две даты | следующие даты с тем же шагом |

![Ряд 1, 2, продолженный маркером](recopie.webp 760x300)

Без мыши или для большого диапазона:

| Команда | Результат |
| --- | --- |
| **%edit% › %fillDown%**, [[Ctrl+D]] | первая строка выделенного диапазона копируется в следующие |
| **%edit% › %fillRight%**, [[Ctrl+R]] | первый столбец копируется в следующие |

Если выделена одна строка, [[Ctrl+D]] копирует в неё строку выше; если один столбец, [[Ctrl+R]] копирует столбец слева. Эти команды всегда копируют, не создавая ряда, вместе с форматами, границами, флажками и списками.

tip: Формула на весь столбец: наберите её сверху, выделите от этой ячейки до последней, [[Ctrl+D]].

=== formules
# Формулы

## Запись формулы {#ecrire}

Формула начинается с `=`. В ней числа, тексты в кавычках, ссылки на ячейки, операторы и [функции](fonctions.html).

```
=B2*2
=(B2+C2+D2)/3
=AVERAGE(B2:B6)
="Итого: "&SUM(B2:B6)
```

Ячейка показывает результат, строка формул — формулу. Ячейки, зависящие от изменённой, пересчитываются сразу.

По-русски запятая десятичная, а аргументы разделяет точка с запятой: `=ROUND(3.14159, 2)`. Имена функций набирают строчными или прописными, по-русски или по-английски: `=сумм(B2:B6)` и `r:=SUM(B2:B6)` принимаются.

## Указание ячеек мышью {#souris}

При наборе формулы щелчок по ячейке листа вставляет её адрес, протягивание — диапазон. У каждой ссылки свой цвет, в формуле и на листе.

## Подсказка имён {#completion}

С первых букв имени DocCells предлагает функции, которые их содержат: [[↑]] [[↓]] для просмотра, [[Enter]], [[Tab]] или щелчок для выбора. После открывающей скобки справка напоминает аргументы.

![Функции, предложенные после первых букв](completion.webp 760x560)

![Справка по функции](aide-formule.webp 760x560)

## Автосумма {#somme}

{formula-sum} записывает сумму. Стрелка предлагает **%sum%**, **%average%**, **%count%**, **%max%**, **%min%** и **%allFormulas%**: библиотеку, где функцию ищут по имени, описанию или категории.

![Библиотека формул](bibliotheque.webp 1280x760)

## Операторы {#operateurs}

| Оператор | Назначение |
| --- | --- |
| `+` `-` `*` `/` | четыре действия |
| `^` | степень: `=2^10` |
| `%` | процент: `=20%*B2` |
| `&` | соединяет тексты: `=A2&" "&B2` |
| `=` `<>` | равно, не равно |
| `<` `>` `<=` `>=` | сравнения |
| `( )` | порядок действий |

Степени идут раньше произведений и частных, затем суммы, затем сравнения. `=-2^2` даёт −4 (в Excel 4).

## Ссылки {#references}

| Запись | Значение |
| --- | --- |
| `B2` | ячейка; следует заполнению |
| `$B$2` | та же ячейка и при заполнении |
| `B$2`, `$B2` | закреплённая строка, закреплённый столбец |
| `B2:D6` | диапазон |
| `B:B`, `2:2` | весь столбец, вся строка |
| `%sheet%2!B2`, `'Оценки 2'!B2` | ячейка [другого листа](feuilles.html#references) |
| `оценки` | [именованный диапазон](noms.html) |

При заполнении вниз `=B2*$B$1` становится `=B3*$B$1`, `=B4*$B$1`…

## Условия {#conditions}

```
=IF(B2>=10, "сдал", "не сдал")
=IF(AND(B2>=10, C2>=10), "да", "нет")
=SWITCH(A2, "a", 1, "b", 2, 0)
=COUNTIF(B2:B6, ">10")
=SUMIF(A2:A6, "Ana", B2:B6)
=AVERAGEIF(B2:B6, "<10")
```

- Логические значения пишутся `@TRUE()` и `@FALSE()`, со скобками. Показываются как TRUE и FALSE.
- Условие — это текст: `">10"`, `"<>0"`, `"Ana"`. Подстановочные знаки `*` и `?` не распознаются.
- Пустая ячейка определяется так: `=B2=""`; она не равна 0.

## Поиск в таблице {#chercher}

```
=VLOOKUP("Léa", A2:D6, 3, 0)
=INDEX(A2:A6, MATCH(MAX(B2:B6), B2:B6, 0))
```

Первая ищет Léa в первом столбце таблицы и возвращает третий; последний аргумент 0 требует точного значения. Вторая даёт имя того, у кого лучшая оценка.

## Даты и время {#dates}

Дата — это число дней, время — доля дня: в ячейках их можно складывать и вычитать.

```
=A2+7
=A3-A2
=DAYS(A3, A2)
=WEEKDAY(A2, 2)
```

Дата, которую дают `@DATE` или `@TODAY`, для сложения должна пройти через ячейку: `=TODAY()+1` даёт `#VALUE!`, но если в A1 стоит `=TODAY()`, то `=A1+1` даёт завтрашний день. Результат — число: задайте ему формат **%fDate%**.

## Ошибки {#erreurs}

| Показано | Причина |
| --- | --- |
| `#NAME?` | неизвестное имя: опечатка, [невычисляемая](fonctions.html#non-calculees) функция, `@TRUE` без скобок, текст без кавычек |
| `#VALUE!` | неожиданный тип: текст там, где нужно число |
| `DIV/0` | деление на ноль или на пустую ячейку |
| `#N/A` | значение не найдено (`@MATCH`, `@VLOOKUP`) или `GEO` вне DocGeo |
| `#REF!` | ячейки или листа не существует |
| `#NUM!` | число вне области определения: `=SQRT(-1)` |
| `#ERROR!` | неверно записанная формула или невычисляемая функция |

`@IFERROR` заменяет ошибку функции (`#N/A`, `#NUM!`): `=IFERROR(VLOOKUP(E1, A2:D6, 2, 0), "нет")`. Ошибку вычисления (`DIV/0`, `#VALUE!`) она не заменяет: от деления на ноль защищает проверка делителя, `=IF(B2, B3/B2, "")`, годная и для нуля, и для пустой ячейки.

=== listes
# Списки и комплексные числа

> Ячейка DocCells может содержать список чисел. Список из двух чисел — это также точка плоскости или комплексное число.

## Запись списка {#ecrire}

В квадратных скобках, элементы через точку с запятой. Список может содержать списки.

```
n:[2, 1]
n:[1.5, -3, 4]
n:[[1, 2], [3, 4]]
=[2, 1]*3
=[B2, C2]
```

Без `=` список — значение; с `=` его элементы могут быть вычислениями. В языке с десятичной точкой элементы разделяют запятыми: `r:[2, 1]`.

## Действия {#operations}

| Действие | Результат |
| --- | --- |
| `n:[1, 2, 3] + [1, 1, 1]` | `n:[2, 3, 4]`: почленно, равные длины |
| `n:[1, 2, 3] * 2`, `n:[2, 4, 6] / 2` | `n:[2, 4, 6]`, `n:[1, 2, 3]` |
| `n:[2, 1] * [3, 2]` | `n:[4, 7]`: произведение комплексных чисел |
| `n:[4, 7] / [3, 2]` | `n:[2, 1]`: частное комплексных чисел |
| `n:[2, 1] + 3` | `n:[5, 1]`: 3 — действительное комплексное число |
| `n:[0, 1]^2` | `n:[-1, 0]`, с точностью до округления |
| `n:[8, 0]^(1/3)` | список трёх кубических корней |
| `n:-[2, 1]` | `n:[-2, -1]` |

Любое другое сочетание даёт `#VALUE!`: произведение двух списков из трёх чисел, разные длины, текст.

## Списки и функции {#fonctions}

Для функции список — то же, что диапазон:

```
=SUM([1, 2, 3])
=MAX(A1)
=INDEX(A1, 2)
=AVERAGE([12, 15, 8])
=SUM([1, 2, 3] + [1, 1, 1]*2)
```

`=INDEX(A1, 2)` даёт второй элемент списка в A1: ординату точки, мнимую часть комплексного числа. Некоторые [функции](fonctions.html) возвращают список: `@FREQUENCY`, `@LINEST`, `@TRANSPOSE`, `@UNIQUE`, `@SPLIT`.

## Отображение {#affichage}

Кнопки {number-decrease} {number-increase} и [числовые форматы](nombres.html) применяются к каждому числу списка: `n:[-0.14, 0.27]`. Точные значения сохраняются.

## Пример: комплексная последовательность {#exemple}

Орбита 0 при *z* ↦ *z*² + *c*: в A1 — *c*, в A2 — `n:[0, 0]`, в A3 — формула ниже, заполненная вниз.

```
=A2^2+$A$1
```

В [DocGeo](docgeo.html) такой столбец рисуется на чертеже.

note: В файле Excel список сохраняется как текст, как и значение формулы, дающей список ([совместимость](excel.html#listes)).

3. Щёлкнуть стрелку столбца.

![Фильтр столбца](filtre.webp 1280x760)

| В меню столбца | Результат |
| --- | --- |
| **%sortByAsc%**, **%sortByDesc%** | сортирует строки таблицы |
| **%filterByColor%** | по цвету фона или текста |
| **%filterByValues%** | отметить оставляемые значения; **%filterAll%**, **%filterNone%**, **%filterInverse%**; поле ищет значение |
| **%filterConfirm%** | применяет |
| **%clearFilter%** | убирает фильтр таблицы |

Отброшенные строки скрываются, а не удаляются. Фильтры нескольких столбцов действуют вместе. **%data% › %sortAndFilter% › %clearFilter%** убирает фильтр.

## Поиск, замена {#rechercher}

[[Ctrl+F]] открывает **%find%**, [[Ctrl+H]] — **%replace%**.

![Поиск](rechercher.webp 1280x660)

| Параметр | Результат |
| --- | --- |
| **%regex%** | искомый текст — регулярное выражение: `^A` находит то, что начинается с A |
| **%wholeWord%** | вся ячейка равна тексту |
| **%matchCase%** | различает прописные и строчные |
| **%findAll%** | перечисляет найденные ячейки; щелчок по строке ведёт к ячейке |
| **%findNext%** | переходит к следующей |
| **%replaceOne%**, **%replaceAll%** | одну ячейку, все |

Поиск ведётся на показанном листе.

=== controles
# Флажки, списки и календарь

![Флажки, раскрывающийся список и календарь даты](controles.webp 1280x560)

## Флажки {#cases}

Выделите ячейки, **%insert% › %checkbox%**. Щелчок ставит или снимает флажок; значение ячейки — TRUE или FALSE.

```
=IF(B2, "сделано", "сделать")
=SUMPRODUCT(B2:B6, C2:C6)
=SUMPRODUCT(B2:B6, B2:B6)
```

Вторая формула складывает значения столбца C с отмеченным флажком; третья считает отмеченные флажки.

## Раскрывающиеся списки {#listes}

Выделите ячейки, **%insert% › %dropdown%**.

| Источник | Содержание |
| --- | --- |
| **%listValues%** | варианты, по одному в поле; **%addOption%**; без запятых |
| **%listRange%** | диапазон, ячейки которого — варианты: `%sheet%2!$A$1:$A$10` |

Диапазон без `$` сдвигается от ячейки к ячейке, как заполненная формула. Если его ячейки меняются, варианты следуют за ними.

В ячейке видна стрелка; щелчок открывает варианты. Значение не из списка не принимается.

## Календарь {#calendrier}

Двойной щелчок по ячейке с датой открывает календарь: выберите день, меняйте месяц кнопками **<** и **>**, **%today%** — сегодняшняя дата. Он открывается в любой ячейке с форматом даты, даже пустой, если в ней нет формулы и она не [заблокирована](protection.html).

tip: Для столбца дат, который заполняют календарём: выделите его и задайте формат **%fDate%**.

## Удаление {#retirer}

[[Delete]] убирает из ячейки флажок или список вместе со значением.

Флажки и списки сохраняются в файле Excel; флажки там — флажки Excel.

=== graphiques
# Диаграммы и спарклайны

## Создание диаграммы {#creer}

1. Выделить данные.
2. {chart} или **%insert% › %chart%**.
3. Выбрать тип и параметры; образец меняется сразу.
4. **%chartAdd%**, затем **%chartClose%**.

![Окно диаграмм](graphique.webp 1280x900)

| Выделено | Понимается как |
| --- | --- |
| столбец или строка чисел | данные |
| два столбца | подписи в первом, данные во втором |
| две строки | подписи в первой, данные во второй |
| два отдельных столбца, выбранные с [[Ctrl]] | то же |

Диаграмма показывает один ряд: строку или столбец данных. Ячейки без числа, например заголовок, пропускаются.

## Типы {#types}

| Тип | Для чего | Подписи |
| --- | --- | --- |
| **%tBar%** | сравнение | под столбиками |
| **%tLine%** | изменение | по оси абсцисс |
| **%tScatter%** | связь двух величин | это абсциссы, если они числа; иначе 1, 2, 3… |
| **%tPie%** | доли; положительные значения | в легенде или на секторах |

До 120 значений, 24 для секторов.

![Четыре типа диаграмм](graphiques.webp 1280x640)

## Параметры {#options}

| Поле | Содержание |
| --- | --- |
| **%chartTitle%** | обязательно; показан вверху диаграммы |
| **%chartColor%** | выбор или код `#4F81BD`; у секторов свои цвета |
| **%chartRange%** | диапазон: `B2:B6` |
| **%chartLabels%** | **%lNone%**; **%lColumn%** (`A`); **%lRow%** (`1`); **%lRange%**, того же размера, что данные |
| **%chartOptions%** | значения, легенда, абсциссы, ординаты, сетка |

## Перемещение, изменение {#modifier}

- Потянув полосу заголовка, перемещают диаграмму; потянув правый нижний угол, меняют размер.
- **%chartEdit%** снова открывает окно, **%chartDelete%** удаляет диаграмму. Окно также перечисляет все диаграммы листа.
- Диаграмма следует данным своих ячеек.

Диаграммы сохраняются в файле Excel как настоящие и снова читаются DocCells. С листом они не [печатаются](impression.html).

## Спарклайны {#sparklines}

Функция `SPARKLINE` рисует в ячейке миниатюрную диаграмму.

```
=SPARKLINE(B2:F2)
=SPARKLINE(B2:F2, {"charttype"\"column"})
=SPARKLINE(B2:F2, {"charttype"\"line", "color"\"#dc2626", "linewidth"\2})
=SPARKLINE(B2:F2, {"charttype"\"bar", "max"\100})
```

![Спарклайны в виде линии и столбиков](sparklines.webp 900x300)

Параметры пишут в фигурных скобках: имя, обратная косая черта, значение; между параметрами точка с запятой.

| `charttype` | Рисунок | Свои параметры |
| --- | --- | --- |
| `"line"` (по умолчанию) | линия | `color`, `linewidth`, `xmin`, `xmax`, `ymin`, `ymax` |
| `"bar"` | полосы с накоплением | `max`, `color1`, `color2` |
| `"column"` | столбики | `color`, `negcolor`, `lowcolor`, `highcolor`, `firstcolor`, `lastcolor`, `axis`, `axiscolor`, `ymin`, `ymax` |
| `"winloss"` | выигрыши и проигрыши | те же, без `ymin` и `ymax` |

Общие параметры: `empty` (`"zero"` или `"ignore"`), `nan` (`"convert"` или `"ignore"`), `rtl` (справа налево). [Документация SPARKLINE](../../sparkline/ru.html) даёт все значения с примерами.

Для рисунка крупнее увеличьте строку и столбец или объедините ячейки.

=== protection
# Защита

> Защищённую книгу можно изменять только в разблокированных ячейках: так готовят лист с заданием.

## Подготовка листа для учеников {#preparer}

1. Выделить ячейки для заполнения, правая кнопка › **%unlock%**.
2. {protect} или **%tools% › %protectWorkbook%**.
3. Сохранить, затем [распространить файл или ссылку](partager.html).

Вначале все ячейки заблокированы; блокировка действует только в защищённой книге. **%lock%** возвращает её.

## Что запрещает защита {#effets}

| В защищённой книге | Заблокированная ячейка | Разблокированная ячейка |
| --- | --- | --- |
| ввод, стирание | нет | да |
| календарь даты | нет | да |
| ширина и высота | нет | нет |
| чередующиеся цвета, вставка флажков и списков, заполнение из меню | нет | нет |
| оформление, вставка строк и столбцов, диаграммы | да | да |

Защита действует на все листы. Она сохраняется в файле Excel вместе с разблокированными ячейками и читается DocCells и Excel.

## Режим ученика {#eleve}

`?mode=student` в адресе открывает DocCells без кнопки {protect} и без команд **%unlock%** и **%defineName%**; **%protectWorkbook%** недоступна. Ученик не может снять защиту.

```
https://…/doccells/?mode=student&url=https://…/zadanie.xlsx
```

note: Это защита без пароля: тот, кто откроет файл в другой программе или без `mode=student`, сможет её снять.

=== partager
# Публикация и встраивание

## Книга по ссылке {#url}

`?url=` и адрес файла `.xlsx` в интернете открывают его в DocCells.

```
https://…/doccells/?url=https://example.org/marks.xlsx
```

Сайт с файлом должен разрешать чтение другим сайтам (заголовок CORS); файла рядом с DocCells, на том же сайте, это не касается. Каждый открывает свою копию: изменения не возвращаются в исходный файл.

## Google Таблица {#google}

Подходит и адрес Google Таблицы.

```
https://…/doccells/?url=https://docs.google.com/spreadsheets/d/…
```

- Откройте к ней доступ «Все, у кого есть ссылка».
- DocCells при каждом открытии читает копию в формате Excel: документ Google не изменяется.
- Сайт с DocCells должен выполнять PHP; не более 25 МБ.

## Параметры адреса {#options}

| Параметр | Результат |
| --- | --- |
| `url=…` | открывает книгу или Google Таблицу |
| `mode=student` | [режим ученика](protection.html#eleve) |
| `lang=ru` | задаёт язык: `de`, `el`, `en`, `es`, `fr`, `hi`, `it`, `nl`, `pt`, `ru`, `zh-CN`, `zh-TW` |

Параметры идут подряд через `&`: `?lang=ru&mode=student&url=…`. Первый стоит после `?`.

## На веб-странице {#integrer}

```

    style="width:100%;height:500px;border:1px solid #ccc"></iframe>
```

Во фрейме у DocCells нет меню, кнопок открытия и сохранения, копии для восстановления: видны панель кнопок, строка формул и лист.

=== docgeo
# С DocGeo

> DocGeo, программа динамической геометрии DocTools, содержит DocCells: лист рядом с чертежом, они читают друг друга.

Интерфейса DocGeo на русском языке нет; ниже даны его английские команды. **File › %gView% › %gSheetView%** добавляет лист рядом с чертежом; **File › %gTab% › %gSheetTab%** делает его вкладкой.

## Функция GEO {#geo}

В ячейке `GEO` читает значение объекта чертежа, указанного именем в кавычках.

```
=GEO("AB")
=2*GEO("r")+1
=GEO("'Figure 1'!c")
```

- Ячейка следует за чертежом, пока его двигают.
- Точка читается как [список](listes.html) координат: `=GEO("A")*2` — тоже точка.
- При наборе формулы щелчок по объекту чертежа вписывает в неё `GEO` и его имя.
- Неизвестный объект даёт `#N/A`. Вне DocGeo `GEO` всегда даёт `#N/A`.
- `GEO` называется одинаково на всех языках.

## Чертёж читает ячейки {#figure}

В формуле DocGeo `!B3` — ячейка, `!B2:B21` — диапазон.

## Отличия от отдельного DocCells {#differences}

| В DocGeo | |
| --- | --- |
| Меню и кнопки | на панелях DocGeo, когда лист активен |
| Файл | файл DocGeo: лист сохраняется в `.dgo` вместе со списками и ссылками |
| Листы | по одному на вид; несколько вкладок с таблицами читают друг друга |
| Отмена | [[Ctrl+Z]] в ячейках отменяет только ячейки |

Подробности — на странице [The spreadsheet](https://doctools.org/apps/docgeo/tutorials/en/tableur.html) руководства DocGeo (по-английски).

# Совместимость с Excel

> DocCells читает и записывает формат Excel `.xlsx`. Следующее сохраняется в обе стороны.

## Что сохраняется {#conserve}

| Элемент | Примечание |
| --- | --- |
| значения, тексты, даты, формулы | формулы показаны на языке DocCells |
| [числовые форматы](nombres.html) | в том числе пользовательские |
| шрифт, цвета, выравнивание, поворот, перенос | |
| границы, объединённые ячейки | |
| ширина, высота, скрытые строки и столбцы | |
| [закреплённые строки и столбцы](lignes-colonnes.html#figer), сетка | |
| несколько листов | |
| [именованные диапазоны](noms.html) | |
| [условное форматирование](conditionnelle.html) | правила DocCells, простые правила Excel (сравнение, содержит текст) |
| [флажки, раскрывающиеся списки](controles.html) | |
| [диаграммы](graphiques.html) | записываются как диаграммы Excel; диаграммы DocCells читаются снова |
| [изображения](images-liens.html) | |
| [фильтры](tri-filtre.html#filtrer) | |
| [защита](protection.html), разблокированные ячейки | |

## Что не сохраняется {#perdu}

| Элемент | Становится |
| --- | --- |
| [ссылки](images-liens.html#liens) | их текстом |
| [списки](listes.html) в ячейках | текстом, `n:[2, 1]` |
| спарклайны DocCells или Google Таблиц | формулой `SPARKLINE`, которую DocCells читает; Excel её не знает |
| диаграммы, созданные в Excel | не сохраняются |
| сводные таблицы, макросы, срезы, комментарии | не сохраняются |
| условное форматирование с цветовыми шкалами, гистограммами, значками | не сохраняется |

tip: Прежде чем заменить сложную книгу Excel, сохраните её из DocCells под другим именем (**%saveAs%**).

## Списки {#listes}

Список, открытый из `.xlsx`, — текст: наберите его снова, и он станет списком. Список, вычисленный формулой, снова становится списком при пересчёте.

## Формулы {#formules}

При открытии формула обычно хранит результат, сохранённый Excel, пока не изменится одна из её ячеек. Функция, [не вычисляемая DocCells](fonctions.html#non-calculees), тогда даёт `#NAME?` или `#ERROR!`.

## Другие форматы {#formats}

| Формат | Как |
| --- | --- |
| `.csv` | откройте файл в текстовом редакторе, скопируйте и вставьте в DocCells, если значения разделены табуляцией; иначе преобразуйте в `.xlsx` |
| `.ods`, `.xls` | сохраните как `.xlsx` в LibreOffice или Excel |
| Google Таблицы | [по ссылке](partager.html#google) или скачав как `.xlsx` |
| PDF | [печать](impression.html), «Сохранить как PDF» |

# Вопросы и ответы

## Ввод {#saisie}

### Набранная дата не распознана

`25.11.2026` для DocCells — текст. Наберите `2026-11-25`, затем выберите формат **%fDate%** ([даты](saisie.html#dates)).

### Вместо даты видно число

Даты — это числа дней: задайте ячейкам формат **%fDate%** (**%format% › %number%**).

### Числа не складываются

Выровненные влево — это тексты. Десятичный разделитель — запятая; единица, набранная в ячейке, превращает число в текст ([типы](saisie.html#types)).

### Исчезает ноль в начале номера

Задайте формат **%fText%** до набора или начните с апострофа ([тексты](saisie.html#textes)).

### Числа требуют точку вместо запятой

DocCells следует языку браузера. `?lang=ru` задаёт его ([язык](demarrage.html#langue)).

## Формулы {#formules}

### `#NAME?` с ИСТИНА или ЛОЖЬ

Пишите `@TRUE()` и `@FALSE()` или 1 и 0 ([условия](formules.html#conditions)).

### `#NAME?` с функцией, предложенной DocCells

Вычисляются не все предложенные функции ([невычисляемые функции](fonctions.html#non-calculees)).

### `@IFERROR` пропускает DIV/0

Проверяйте делитель: `=IF(B2, A2/B2, "")` ([ошибки](formules.html#erreurs)).

### При вставке пропадают формулы

**%paste%** в меню правой кнопки вставляет значения; [[Ctrl+V]] вставляет формулы ([копирование](selection.html#copier)).

### Как записать название месяца или оформить число в тексте

Функция `@TEXT` не вычисляется: задайте [формат](nombres.html) отдельной ячейке.

### Подсчёт отмеченных флажков

`=SUMPRODUCT(B2:B6, B2:B6)` ([флажки](controles.html#cases)).

### `=TODAY()+1` даёт #VALUE!

Поместите `=TODAY()` в ячейку и прибавляйте к ней ([даты](formules.html#dates)).

## Оформление {#presentation}

### Цвет ячейки не меняется

Ячейка входит в диапазон правила [условного форматирования](conditionnelle.html#regles).

### Пропала кнопка

Окно узкое: она за {more}.

### Сортировка или фильтр невозможны

В диапазоне есть объединённые ячейки: отмените объединение.

## Файлы {#fichiers}

### Сохранение скачивает новый файл

Так в Firefox и Safari. Chrome и Edge записывают в файл ([сохранение](demarrage.html#enregistrer)).

### Страница закрылась без сохранения

Снова откройте DocCells в том же браузере: он предложит восстановить копию ([восстановление](demarrage.html#recuperer)).

### Диаграмма не печатается

Печатаются только ячейки ([печать](impression.html)).

### Ссылка `?url=` не открывает книгу

Возможно, сайт файла запрещает чтение другим сайтам. К Google Таблице нужен доступ по ссылке ([публикация](partager.html)).

### Пропали ссылки

Они не сохраняются в формате Excel ([что не сохраняется](excel.html#perdu)).

## Ученики {#eleves}

### Может ли ученик изменить формулы?

В защищённой книге — только в разблокированных ячейках ([защита](protection.html)). `mode=student` в ссылке лишает его возможности снять защиту.
